Listado de endpoints REST, ejemplos de request/respuesta y pautas de autenticación.
Base URL
https://api.tu-dominio.com/v1
Autenticación

Bearer token (JWT). Agregar cabecera Authorization: Bearer <token> a endpoints protegidos.

POST /auth/login
Obtener token de acceso (email o cédula + contraseña)
Público
Request
{
  "identifier": "estudiante@ejemplo.com", // o cédula
  "password": "mi_contraseña"
}
Respuesta (ej.)
{
  "access": "eyJ...",
  "refresh": "eyJ...",
  "user": {"id": 12, "nombre": "Ana", "rol": "student"}
}
curl -X POST https://api.tu-dominio.com/v1/auth/login -H 'Content-Type: application/json' -d '{"identifier":"estudiante@ejemplo.com","password":"mi_contraseña"}'
GET /users
Listar usuarios (admin)
Protegido (admin)
Query params
?page=1&limit=20&rol=student&grupo=3
Respuesta (ej.)
{
  "count": 120,
  "results": [{"id":1,"nombre":"Juan","rol":"student","cedula":"01010101"}, ...]
}
POST /users
Crear usuario
Protegido (admin)
Request (ej.)
{"nombre":"María","email":"maria@ejemplo.com","cedula":"01020304","rol":"student","password":"pass1234"}
GET /groups
Listar grupos
Protegido (docente/admin)
Crear grupo
POST /groups {"nombre":"Grupo A","periodo":"2025-1","miembros":[12,13,14]}
POST /evaluations
Crear evaluación (docente)
Protegido (docente)
Request (ej.)
{
  "titulo":"Evaluación Estrés - Parcial 1",
  "descripcion":"12 preguntas - 4 categorías",
  "preguntas":[ {"texto":"¿Te sientes...","categoria":"emocional","tipo":"likert","opciones":["Nunca","Rara vez","A veces","Frecuente"]}, ...],
  "visible_por_defecto": true
}
POST /evaluations/{id}/assign
Asignar evaluación a estudiantes o grupos
Protegido (docente)
Request (ej.)
{"asignados":{"usuarios":[12,13],"grupos":[3]},"fecha_inicio":"2025-11-20","fecha_fin":"2025-12-05"}
GET /students/{id}/evaluations
Historial de evaluaciones realizadas por un estudiante
Protegido (estudiante / docente con permiso)
Respuesta (ej.)
{"evaluaciones":[{"id":45,"titulo":"Evaluación 1","fecha":"2025-06-10","resultado":{"nivel":"medio","score":7.5}}]}
POST /evaluations/{id}/submit
Enviar respuestas de un estudiante
Protegido (estudiante)
Request (ej.)
{"respuestas":[{"pregunta_id":1,"respuesta":2},...] , "config":{"compartir_con_docente": true}}
GET /notifications
Listar notificaciones (usuario)
Protegido (usuario autenticado)
POST /notifications enviar notificación (admin/docente) con payload {"titulo":"...","mensaje":"...","usuarios":[12],"tipo":"alert"}
GET /stats/evaluations/summary
Resumen estadístico por curso/grupo (docente/admin)
Protegido (docente/admin)
Query params: ?grupo=3&periodo=2025-1

Guía rápida

Buenas prácticas
  • Usa paginación en listados grandes (page & limit).
  • Valida roles en el backend (admin/docente/estudiante).
  • Almacena JWT en cookies HttpOnly o en almacenamiento seguro.
  • Registra eventos importantes (creación/edición/asignación).
